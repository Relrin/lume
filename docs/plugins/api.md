# Plugin API reference

Generated by `cargo xtask api` from Lume's definitions of the API. Every call
returns a promise; a call that fails rejects it with a `LumeError`, whose `code`
says why (`denied`, `invalid`, `not_found`, `busy`, `failed`, `stopped`). The
calls that only change what the plugin shows (`status.set`, `status.clear`,
`context.set`, `panels.set`, `panels.clear`, `panels.setChildren`) are not
answered: their promise is settled at once, and a failure goes to the plugin's
log.

Besides the calls below, the API has `lume.self`, `lume.commands.register`,
`lume.timers`, `lume.sessions.onEvent`, `lume.settings.onChange`,
`lume.metrics.subscribe`, `lume.log`, `lume.onDeactivate` and `console`; the
typings describe them.

### `lume.streams.grantToView(instance, stream)`

Lets one of the plugin's open views use one of its streams directly: the bytes
 then go between the view and the stream without passing through the plugin's
 code. Gives a grant, which the code hands the view (with `views.post`, or as a
 call's answer) and the view opens with `streams.open(grant)`. A grant is for
 that one view and is opened once; it ends when the view closes, the stream
 closes, or it is revoked.

| Argument | Type | |
|---|---|---|
| `instance` | `string` | The open view that may use the stream, by its instance. |
| `stream` | `number` |  |

Gives `string`.

### `lume.streams.revoke(grant)`

Takes back a grant: a view that had opened it is told its stream has ended.

| Argument | Type | |
|---|---|---|
| `grant` | `string` | What `streams.grantToView` gave. |

Gives `void`.

## lume.views

### `lume.views.post(to, event, payload?)`

Sends an event to the plugin's own open views: to one, by its instance, or to
 every open one of a view, by the view's name. A view hears it with
 `host.on(event, …)`; views that are not open miss it.

| Argument | Type | |
|---|---|---|
| `to` | `string` | An open view's instance, or a view's name for every open one of it. |
| `event` | `string` | The event's name, as the view listens for it. |
| `payload` | `Json` | optional.  |

Gives `void`.

### `lume.views.instances(view?)`

The plugin's views that are open now, in every window: all of them, or those of
 one view by its name.

| Argument | Type | |
|---|---|---|
| `view` | `string` | optional. One view's name; all of the plugin's views when left out. |

Gives `ViewInstance[]`.
