# Plugin API reference

Generated by `cargo xtask api` from Lume's definitions of the API. Every call
returns a promise; a call that fails rejects it with a `LumeError`, whose `code`
says why (`denied`, `invalid`, `not_found`, `busy`, `failed`, `stopped`).

Besides the calls below, the API has `lume.self`, `lume.commands.register`,
`lume.timers`, `lume.sessions.onEvent`, `lume.settings.onChange`, `lume.log`,
`lume.onDeactivate` and `console`; the typings describe them.

## lume.commands

### `lume.commands.execute(id, args?)`

Runs a command: one of the plugin's own, by its name, or one of the
 application's that plugins may run. Its arguments are a JSON object.

| Argument | Type | |
|---|---|---|
| `id` | `string` | The command's id: one of the application's, or one of the plugin's own by its name. |
| `args` | `Json` | optional.  |

Gives `void`.

## lume.context

| Argument | Type | |

## lume.settings

### `lume.settings.get(key?)`

One of the plugin's settings, by its key, or all of them as an object when no
 key is given. A setting the user has not set has its default.

| Argument | Type | |
|---|---|---|
| `key` | `string` | optional. One setting, by its key; all of the plugin's if left out. |

Gives `Json`.

## lume.status

### `lume.status.set(id, value, pane?)`

Shows something in one of the plugin's status items. Fields left out keep what
 the item showed before.

| Argument | Type | |
|---|---|---|
| `id` | `string` | The status item, by the name the manifest gives it. |
| `value` | `StatusValue` |  |
| `pane` | `string` | optional. The pane whose header shows it, for an item in a pane's header. |

Gives `void`.

### `lume.status.clear(id, pane?)`

Takes back what a status item showed, so it shows what its manifest says.

| Argument | Type | |
|---|---|---|
| `id` | `string` |  |
| `pane` | `string` | optional.  |

Gives `void`.

### `StatusValue`

What a status item shows. Each field left out keeps what the item showed before;
the manifest says what kind of item it is.

| Field | Type | |
|---|---|---|
| `card` | `CardRow[]` | optional. The rows of the card shown when the pointer rests on the item. |
| `hidden` | `boolean` | optional. Whether the item is out of sight for now. |
| `label` | `string` | optional. What the item stands for, read out and shown beside a meter. |
| `points` | `number[]` | optional. A sparkline's values, from the oldest to the newest. |
| `text` | `string` | optional. The words of a text or badge item, or the amount written out beside a meter or a sparkline. |
| `tone` | `Tone` | optional.  |
| `tooltip` | `string` | optional. What the pointer is told when it rests on the item. |
| `value` | `number` | optional. How full a meter is, from 0 to 1. |
